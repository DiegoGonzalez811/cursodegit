## Sobre el curso
Este repositorio forma parte de la entrega final de un curso de gestión de proyectos con Git. Aquí se aplican prácticas de trabajo colaborativo, uso de ramas y documentación.

## Herramientas para aprender Git y ramas
1. [learngitbranching.js.org](https://learngitbranching.js.org/) - Simulador interactivo para entender cómo funcionan las ramas.
2. [git-school.github.io/visualizing-git](https://git-school.github.io/visualizing-git/) - Visualizador para practicar Git paso a paso.
